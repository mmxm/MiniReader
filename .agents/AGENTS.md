# Règles comportementales de l'agent MiniReader

## Règles de planification
- **Toujours proposer un plan d'implémentation** détaillé dans `implementation_plan.md` et demander l'approbation explicite de l'utilisateur (via `RequestFeedback: true`) avant d'apporter la moindre modification aux fichiers sources du projet ou aux fichiers de ressources statiques.

## Règles de restitution (Git / Commits)
- **Toujours préciser explicitement le hash de commit (court et long)** dans le message de conclusion après chaque opération de `push` sur le dépôt distant.
